# Contact Books PaperPlane

A simple and responsive **Contact Management Application** built using React.js. This application allows users to manage their contacts through an easy-to-use interface.

## 🚀 Features

* Add new contacts
* View contact details
* Edit existing contacts
* Delete contacts
* Search contacts
* Responsive user interface
* Clean and simple design
* Component-based React architecture

## 🛠️ Technologies Used

* React.js
* JavaScript (ES6+)
* HTML5
* CSS3
* Vite
* Git & GitHub
* Vercel

## 🌐 Live Demo

https://contact-books-paper-plane-gray.vercel.app/

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/anmolagrahari24/Contact-Books-PaperPlane.git
```

### 2. Navigate to the project

```bash
cd Contact-Books-PaperPlane
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will run on:

```text
http://localhost:5173
```
